# Actividad MongoDB - Sistemas de Bases de Datos

Aplicación backend desarrollada con Node.js, Express y MongoDB utilizando Mongoose.

## Tecnologías utilizadas

- Node.js
- Express
- MongoDB
- Mongoose
- Postman

## Funcionalidades

### Clientes
- Crear clientes
- Listar clientes
- Actualizar clientes
- Eliminar clientes

### Pedidos
- Crear pedidos
- Listar pedidos
- Actualizar pedidos
- Eliminar pedidos

## Relaciones

Cada pedido pertenece a un cliente mediante referencias ObjectId.

## Instalación

```bash
npm install
```

## Ejecución

```bash
npm run dev
```

## Base de datos

MongoDB local:

```text
mongodb://localhost:27017/act-mongodb-sbd
```
